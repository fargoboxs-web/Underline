# ADR 0001: Local-First Self-Use Product

## Status

Accepted

## Decision

Underline v1 is a local-first self-use product. The primary success criterion is that one operator can use it frequently on ordinary web articles without debugging the stack.

## Consequences

- Public distribution is deferred.
- The single recommended operator path is `npm run demo:start`.
- Reliability, provenance, and persistence matter more than feature breadth.
